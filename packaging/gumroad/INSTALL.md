# Installing ShutterstockAnalyzer

## 1. Run the app

Double-click `ShutterstockAnalyzer.exe`. No installation, no admin
rights needed. Windows may show a SmartScreen warning ("Windows
protected your PC") because the binary isn't code-signed -- click
**More info -> Run anyway**.

## 2. Optional dependencies

- **ExifTool** (recommended) -- enables reading/writing IPTC metadata
  directly on your image files. Download: https://exiftool.org
  Without it, the app still works but metadata read/write is disabled.
- **Ollama** (optional) -- enables local AI enrichment (auto-generated
  titles/keywords from image content). Download: https://ollama.com
  Without it, the heuristic (non-AI) analysis still works fully.

## 3. Activate your lifetime license

You purchased unlimited data export. Your license key arrives as a
JSON file by email, separately from this package (usually within a
few hours of your Gumroad purchase).

1. Open the app.
2. In the **PARAMÈTRES** panel (bottom right), click **Modifier…**
   (Settings). Scroll to the **Licence** section.
3. Open the `.json` file you received, copy its full contents.
4. Paste it into the field "Coller votre clé de licence (JSON)".
5. Click **Activer** (Activate).

You should see "Édition Pro -- licence à vie -- your@email.com" in
the topbar. From there, data export is unlimited, offline, forever --
no renewal, no subscription.

Haven't received your key yet? Reply to your Gumroad purchase receipt.

## 4. Everything else was already free

The expert report, AI enrichment, dual-platform CSV, and FTP push
work fully without any key -- only the *export* step was metered
(3 free runs before this purchase).
