# Shutterstock AI Metadata Generator v1.0.0

## 🎉 First Stable Release

AI-Powered Metadata Generator for Stock Photography.

### ✨ Features

- **AI Analysis**: Automatic image content analysis
- **Keyword Generation**: Generate relevant keywords for stock photos
- **IPTC Metadata**: Write metadata to images
- **Batch Processing**: Process entire photo collections
- **Shutterstock Compatible**: Output format for Shutterstock uploads

### 📦 Downloads

| File | Description |
|------|-------------|
| `ShutterstockAnalyzer-1.0.0-release.exe` | Production build (no console) |
| `ShutterstockAnalyzer-1.0.0-debug.exe` | Debug build (with console) |

### 🔧 Requirements

- Windows 10/11
- No installation required
- Internet connection for AI features

### 📝 Keywords

Stock photography, AI metadata, keyword generator, IPTC editor, Shutterstock tools
