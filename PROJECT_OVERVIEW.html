ShutterstockAnalyzer

Générateur local de métadonnées microstock (Adobe Stock + Shutterstock) avec IA optionnelle via Ollama. Freemium : tout est gratuit (scan / IPTC / rapport expert / IA / dual CSV / FTP) ; seul l'export de données est limité à 3 essais, puis débloqué à vie pour 10 €.

v2.2.0 Stable Python 3.11+ MIT Windows 10/11 121 tests verts ~25 Mo EXE

Architecture

main.py  →  app.main:main()
    │
    ├─ ShutterstockAIv2 (facade)   ← src/modules/integration.py
    │   ├─ Database               ← src/modules/storage  (SQLite local)
    │   ├─ MetadataReader/Writer  ← src/modules/engines  (ExifTool subprocess)
    │   ├─ WorkerPool             ← src/modules/workers  (threads)
    │   ├─ VisionAnalyzer         ← src/modules/ai       (Ollama, optionnel)
    │   ├─ build_expert_report    ← src/modules/analysis/expert_report
    │   ├─ run_export_batch       ← src/modules/export/batch
    │   ├─ csv_exporter           ← src/modules/export/csv_exporter
    │   └─ ftp_uploader           ← src/modules/export/ftp_uploader
    │
    └─ App(CTk)                     ← app/app.py
        ├─ WorkspaceView (home — Sources, Éditeur IPTC, Analyse IA + 4 panneaux)
        └─ 6 modaux : settings, audit, ai_control, validate,
                      expert_report, export_batch

L'UI passe uniquement par la facade. Aucun import direct de src.modules.* dans app/views/*. Détails complets dans docs/ARCHITECTURE.md.
